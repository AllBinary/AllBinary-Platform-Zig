                             AllBinary Platform Zig

What is it?

This repository contains code generated by the AllBinary Platform for support in Zig.  
This repo is used to allow developers to skip the Zig code generation step.

What are some examples game with this Zig code?

https://allbinary.itch.io (The downloads with "-ts" in the filename are Zig only builds. Currently that only includes nothing. Also the Zig builds are not available on Google Play or other stores.)
